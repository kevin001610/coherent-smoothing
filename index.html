程式一 · EXAMPLE 1

Shan-Kailath 空間平滑與秩恢復

問題
三個方向的到達波完全相干時，共變異數矩陣的秩從 3 塌成 1，MUSIC 找不到正確方向。
解法
把陣列切成重疊的子陣，平均各子陣的共變異數，秩就回來了。

程式二 · EXAMPLE 2

Frost 與平滑 Frost 波束成形

問題
約束式 LMS 波束成形器遇到相干干擾，會把想要的訊號一起抵消。

基礎 1

陣列怎麼分辨方向

均勻線性陣列（ULA）是 M 個等間距排成一線的感測器。平面波從偏離正前方 θ 的方向斜著進來時，波前會依序掃過每個元件，相鄰元件收到的訊號差一段固定的時間延遲 d·sinθ / c。對窄頻訊號而言，時間延遲就是相位旋轉，所以每個方向都對應一組專屬的相位階梯。把這 M 個相位寫成一個複數向量，就是導向向量 a(θ)。

相鄰元件相位差

上方斜線是波前，間隔一個波長。下方每個圓盤的指針是該元件收到的相位。θ = 0° 時波前同時到達，所有指針同向；θ 越大，相鄰指針轉得越多。陣列就是靠這個轉速分辨方向。

程式設定 dLambda = 0.5，也就是元件間距為半個波長。這是空間取樣不發生混疊的最大間距：間距再大，不同方向會產生一模一樣的相位階梯（柵瓣），陣列就分不出來。聲納、雷達、基地台天線與麥克風陣列估計來波方向（DOA）與做波束成形，用的都是這組相位差。

對照程式：導向向量 
steer = @(m,theta) exp(-1j*2*pi*dLambda*(0:m-1).'*sind(theta));
A = steer(M,thetaTrue);   % M×K，每一行是一個方向的相位階梯
基礎 2

相干：三個方向，同一個波形

兩支程式用同一個情境：0° 是想要的訊號，−30° 與 +30° 是干擾。關鍵在於三個到達波都是同一個波形 s0 乘上不同的複數增益 α（振幅與相位不同），也就是完全相干。物理上這就是多路徑：水下聲波經海面與海底反射、低仰角雷達波經海面反射、室內無線電經牆面反射，或是干擾機把你的訊號轉發回來。到達陣列的都是同一個訊號的複本。

訊源關係

三個到達波的實部，取 60 個快照。相干時三條線只差一個固定的比例與相位，形狀完全綁在一起；互不相關時各走各的。

陣列資料的共變異數可以寫成下式，其中 Rs 是訊源之間的相關矩陣：

R = E[ x xH ] = A Rs AH + σ² I

訊源互不相關時 Rs 是對角矩陣，秩等於訊源數 K = 3，R 會有 3 個大特徵值，撐起一個三維的訊號子空間。完全相干時 Rs = α αH，秩只有 1。物理圖像是：三個平面波在陣列上疊成一個固定不動的干涉圖樣 Aα，每個快照只是這個圖樣乘上一個純量。對陣列而言，場上看起來只有「一個」訊源，而且它的空間圖樣不是任何單一方向的導向向量。

對照程式：產生相干資料 
s0 = (randn(1,N)+1j*randn(1,N))/sqrt(2);          % 唯一的波形
alpha = [1; 2.2*exp(1j*0.55); 1.8*exp(-1j*0.90)];  % 三條路徑的複數增益
S = alpha*s0;                                      % rank(S) = 1
Xsig = A*S;
noisePower = mean(abs(Xsig(:)).^2)/10^(SNRdB/10);
V = sqrt(noisePower/2)*(randn(M,N)+1j*randn(M,N));
X = Xsig + V;                                      % M×N 快照矩陣
程式一 · EXAMPLE 1

把陣列切成子陣，秩就回來了

空間平滑的做法是拿一個長度 L 的窗在陣列上滑動，得到 P = M − L + 1 個重疊的子陣。每個子陣看到的是同一組到達波，但因為子陣位置平移，三個到達波之間的相對相位各自多轉了一個不同的角度。把各子陣的共變異數取平均，等於對這些相對相位做平均，到達波之間的交叉項互相抵消，Rs 就恢復成滿秩。

RF = (1/P) Σp Rp ，　RFB = ½ ( RF + J RF* J )

RFB（前後向平滑，FBSS）再把陣列前後翻轉並取共軛。對稱的線性陣列倒過來看仍是合法的陣列，所以等於免費多了一倍的子陣。代價是有效孔徑從 M 縮成 L，主瓣變寬、角度解析度下降。

情境參數

訊源關係

特徵值分布與數值秩

特徵值由大到小排列，以最大值為 0 dB。高於 −12 dB 教學門檻的個數當作數值秩。大特徵值代表訊號子空間的維度，其餘是雜訊底。

MUSIC 利用的是正交性：真實方向的導向向量落在訊號子空間內，與雜訊子空間 En 正交，分母趨近零而出現尖峰。

P(θ) = 1 / ‖ EnH a(θ) ‖²

相干時訊號子空間只剩一維，而且指向的是合成圖樣 Aα。程式仍假設 K = 3，等於把兩個其實屬於雜訊的特徵向量當成訊號，沒有任何 a(θ) 與剩下的雜訊子空間正交，峰值就落在錯的位置。

MUSIC 空間頻譜

垂直虛線是真實方向 −30°、0°、+30°。程式最後用 assert 驗收：FBSS 的三個峰值必須都落在真實方向 2° 以內。

  • 把 L 調到 10：只剩 1 個子陣，前向平滑等於沒做，秩維持 1；FBSS 靠翻轉多出一個等效子陣，也只能恢復到 2。
  • 切到「互不相關」：未平滑的共變異數本來就有 3 個大特徵值，MUSIC 不需要平滑就能解出方向。空間平滑是專門治相干的藥。
  • 把 L 調小：子陣變多、去相關更徹底，但 MUSIC 的峰變鈍，這是孔徑縮小的代價。
對照程式：平滑、特徵值、MUSIC 
Rraw = X*X'/N;                         % 未平滑共變異數 (M×M)

RF = zeros(L,L);
for p = 1:P
    Xp = X(p:p+L-1,:);                 % 第 p 個子陣的資料
    RF = RF + Xp*Xp'/N;
end
RF = RF/P;                             % 前向平滑
J = fliplr(eye(L));
RFB = 0.5*(RF + J*conj(RF)*J);         % 前後向平滑

% eigdb：特徵值排序後換成相對 dB
e = sort(real(eig((R+R')/2)),'descend');
edB = 10*log10(max(e/e(1),1e-12));
rRaw = sum(eRaw > rankThresholdDB);    % 門檻 -12 dB

% music_spectrum：取第 K+1 個以後的特徵向量當雜訊子空間
En = V(:,K+1:end);
denominator = sum(abs(En'*Agrid).^2,1);
P = 1./max(denominator,eps);
程式二 · EXAMPLE 2

Frost 波束成形器為什麼會消掉自己的訊號

Frost 演算法解的是一個帶約束的最小化問題：讓輸出功率 wHRw 最小，同時規定 0° 方向的增益固定為 1（wHa0 = 1）。直覺是：目標方向的增益既然鎖住了，把總輸出功率壓到最低，就等於把其他方向的干擾和雜訊壓到最低。每收到一個快照，權重更新一次：

w ← F + P ( w − μ x y* ) ，　F = a0 / (a0Ha0) ，　P = I − a0a0H / (a0Ha0)

F 是滿足約束、長度最短的權重，也是初始值。梯度步會讓 w 離開約束面，P 把與 a0 平行的分量去掉，再加回 F，就準確落回面上。因為每一步都重新投影，捨入誤差不會累積，程式印出的 constraint residual 在 10⁻¹⁶ 等級。

問題出在約束只鎖住「從 0° 進來的那一路」。±30° 進來的是同一個波形的複本，演算法會發現：把 ±30° 的響應調成恰當的振幅與相位，就能拿它們去抵消 0° 那一路，輸出功率更低。它完全照規則做事，結果是想要的訊號被自己的回音消掉，這叫訊號抵消（signal cancellation）。程式用相干場增益量這件事：

g = wH A α ，　輸出 y = g · s + 雜訊

|g| = 1 表示訊號原樣通過，|g| → 0 表示訊號被消光。平滑 Frost 的修法是只用一組長度 L 的權重，每個快照依序拿 P 個子陣各更新一次，再把各分支輸出平均。這樣梯度的期望值用到的是平滑後的 RF，演算法看到的干擾與訊號相關性下降。去相關越徹底，它越沒辦法借 ±30° 的複本來抵消訊號，只能改成把這兩個方向的響應壓低。

輸出波形與想要的訊號

穩態區間（最後 35% 的快照）開頭的 250 點，取實部。上圖是傳統 Frost，下圖是平滑 Frost，黑線都是想要的訊號 s。

  • 按「播放收斂過程」，看傳統 Frost 的 |g| 怎麼掉下去。它的波束圖在 ±30° 始終沒有形成深零點，因為它需要留著這兩路來抵消訊號。
  • 預設 L = 8（3 個子陣）去相關不完全：平滑 Frost 的 |g| 停在 0.67 左右，±30° 的響應也只壓到約 −12 dB。原因是每平移一個子陣，0° 與 ±30° 的相對相位轉 90°，+30° 與 −30° 之間轉 180°，3 個子陣平均後還殘留 1/3 的相關性。
  • 把 L 調到 7（4 個子陣）：90° 轉四次剛好繞滿一圈，交叉項完全抵消，|g| 回到 1，±30° 出現深零點。這是這組角度配上半波長間距的結果，換一組角度，最合適的 L 也會不同。
  • 把 L 調到 10：只有 1 個子陣，平滑 Frost 退化成傳統 Frost，兩條曲線重合。
  • 切到「互不相關」：傳統 Frost 不再抵消訊號，輸出波形跟得上想要的訊號。問題的根源是相干，不是 Frost 演算法本身。
對照程式：Frost 與平滑 Frost 的主迴圈 
a0M = AM(:,1);                          % 0° 的導向向量
FM = a0M/(a0M'*a0M);                    % 滿足約束的最小範數權重
PM = eye(M)-a0M*((a0M'*a0M)\a0M');      % 投影矩陣
wRaw = FM;

for n = 1:N
    % 傳統 Frost：整個陣列，每個快照更新一次
    x = X(:,n);
    y = wRaw'*x;
    wRaw = FM + PM*(wRaw-muRaw*x*conj(y));
    yRaw(n) = wRaw'*x;

    % 平滑 Frost：同一組 wSS 依序看過 P 個子陣
    branchOut = zeros(Pn,1);
    for p = 1:Pn
        xp = X(p:p+L-1,n);
        yp = wSS'*xp;
        wSS = FL + PL*(wSS-muSS*xp*conj(yp));
        branchOut(p) = wSS'*xp;
    end
    ySS(n) = mean(branchOut);           % 正前方不需對齊分支相位
end

gFieldRaw = wRaw'*AM*alpha;             % 相干場增益
整理

兩個方法各管一件事

方法解決什麼沒解決什麼
Frost 約束投影自適應過程中目標方向增益永遠維持為 1共變異數缺秩。相干干擾仍會抵消訊號
Shan-Kailath 空間平滑把相干資料的共變異數恢復成滿秩孔徑由 M 縮成 L，解析度下降；只適用等間距線性陣列這類具平移不變結構的陣列

程式結尾的註解講的就是這件事：約束投影不等於秩恢復，兩者互補。選 L 是工程上的取捨。L 大，孔徑大、解析度高，但子陣少、去相關能力弱；L 小則相反。前向平滑要解 K 個相干訊源，需要子陣數 P ≥ K 且子陣長度 L ≥ K + 1，合起來是 M ≥ 2K 個元件；前後向平滑可以放寬到大約 M ≥ 3K/2。程式的兩個 assert(L >= K)、assert(P >= K) 檢查的就是前向平滑的條件。

實際會用到這套方法的場合，共同點是多路徑造成相干到達波：淺海聲納與水下通訊的海面、海底反射，低仰角雷達的海面鏡像，室內或都會區基地台的 DOA 估計，以及混響房間裡的麥克風陣列與助聽器。
